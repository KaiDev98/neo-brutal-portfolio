# Neo‑Brutal Portfolio

Starter Next.js (app router) single-page portfolio with a Neo‑Brutalism + Sci‑Fi aesthetic. Built with React (Next.js), Tailwind CSS, and Framer Motion. Includes dummy data you can replace later.

Quick start

1. Clone the repo or download the ZIP from GitHub.
2. Install dependencies:

```bash
npm install
```

3. Run the dev server:

```bash
npm run dev
```

4. Open http://localhost:3000

Notes

- Replace dummy content in `lib/data.js`.
- Palette and design tokens are in `tailwind.config.js` and `styles/globals.css`.
- This project uses the Next.js app router (`app/`).
